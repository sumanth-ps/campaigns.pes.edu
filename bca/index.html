Overview

Bachelor of Computer Applications (BCA)

The Bachelor of Computer Applications (BCA) is a three-year undergraduate programme offered across six semesters. It is designed to build a strong foundation in computer science, programming and application development. The curriculum introduces students to Python, C, Java, data structures, algorithms, databases, operating systems, computer networks, software engineering and web technologies. As students progress, they gain exposure to mobile application development, software testing, artificial intelligence, cloud technologies, cybersecurity, blockchain, multimedia design and human-computer interaction. Choice-based electives allow students to explore selected areas such as application development, graphic design, animation, gaming, software testing, cloud technologies, digital marketing and user experience design. Practical sessions, experiential-learning activities, case studies and project-based assignments are integrated throughout the programme to strengthen problem-solving and software-development skills. Graduates are prepared for careers in software development, web and mobile application development, data analytics, software testing, cloud support, cybersecurity, entrepreneurial ventures and related technology roles. The programme also provides a strong academic base for pursuing MCA and other postgraduate programmes in computer science and information technology.

How We Teach

Pedagogy Method

An overview of the methods and techniques used to disseminate knowledge among our BCA students are as follows…

Lectures

The traditional lecture format is often used to deliver course material, provide context, and introduce new topics. Lectures are also supplemented with multimedia resources, such as videos and slides.

Practical Classes Through Labs

Labs that provide hands-on experience with computer programming, software development, and database management. These practical classes are designed to help our students apply what they have learned in theory.

Projects

Projects which are both individual and group projects. This approach allows students to apply their learning to real-world problems and gain experience working on complex software development projects.

Group Discussions

This facilitates peer-to-peer learning amongst our students and foster collaborative problem-solving.

Online Learning Through PESU Academy

Online learning through our in-house build ERP system – PESU Academy, is encouraged amongst our students. PESU Academy consists of full stack of professionally prepared videos, PPT slides, notes, question bank, reference materials etc…This approach provides greater flexibility for our students to learn at their own pace and access course material at any time.

Careers

Future Career Prospects after completing the Program

The BCA curriculum provides students with skills in programming, web technologies, mobile application development, data analytics, IoT, networking, cybersecurity, software testing, cloud technologies, artificial intelligence, blockchain and user experience design. The career opportunities are:

Web Design and Development


Students are introduced to Web Design using HTML, CSS, JavaScript and Adobe Dreamweaver. Their knowledge is extended through Dynamic Web Application Development. These courses prepare students to design responsive, interactive and database-driven websites for e-commerce, finance, hospitality, education, transportation and other domains.

Full-Stack Development


Knowledge gained through Python, C, Java, web design, dynamic web applications, databases, software engineering, version control systems and cloud technologies prepares students for full-stack development roles. Career opportunities are available in service-based and product-based companies.

Mobile Application Development


The Mobile App Development course provides hands-on experience with Dart, Flutter, Firebase, REST APIs, local storage and cloud databases. Students are prepared to develop responsive cross-platform applications and participate in mobile application deployment.

UI and UX Design


Web Design, Graphic Design and Human-Computer Interaction courses develop skills in interface design, user experience, typography, colour theory, responsive layouts and accessibility. Career opportunities can be pursued in UI design, UX design, mobile interface design, web interface design and digital product design.

Artificial Intelligence, IoT and Data Science


The curriculum includes Artificial Intelligence, Prompt Engineering, IoT Application Development and Storytelling with Data. Students gain experience in machine learning concepts, generative AI tools, connected devices, sensor-based applications, dashboards, data visualization and data interpretation. These skills support careers in AI application support, prompt engineering, IoT development, data analytics, business intelligence and entry-level machine learning roles.

Network Management


Data Communications and System and Data Management provide a foundation in networking, operating systems, Linux utilities, databases and system administration. Students can pursue entry-level roles in network support, infrastructure monitoring and system administration. Further training in SNMP tools and network automation can support progression into network management.

Network Security and Blockchain


Cryptography, Data Communications, System and Data Management and Blockchain and dApp Development provide knowledge of information security, encryption, authentication, distributed ledgers, smart contracts and decentralized applications. These courses support entry-level careers in cybersecurity, security operations, blockchain development and decentralized application development.

Software Testing and Quality Assurance


The curriculum offers Software Testing Fundamentals and Quality Assurance, Software Testing Automation using Selenium and Software Testing and Automation. Students are trained in test planning, test-case development, defect management, functional testing, non-functional testing, API testing and browser automation. Career opportunities include manual tester, quality assurance
analyst, Selenium automation tester and software test engineer.

Cloud Technologies


Cloud Technologies and cloud-integrated application development provide exposure to cloud platforms, cloud storage, databases and application deployment. These skills support entry-level opportunities in cloud support, cloud application development and deployment operations.
